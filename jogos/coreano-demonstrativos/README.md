# 이·그·저 Pop!

Jogo em HTML5 + JavaScript + Three.js para praticar os demonstrativos coreanos
(aula de 17/10/2026, TOPIK I, Ponto A: 이 · 그 · 저 + N).

Abra `index.html` no navegador (precisa de internet para carregar o Three.js e as fontes).

- **Nível 1:** 이 · 그 · 저 + substantivo (escolher a forma e apontar o objeto na cena 3D)
- **Nível 2:** 이거 · 그거 · 저거 뭐예요? e 이것은 …이에요/예요
- **Nível 3:** troca de quem fala (준호), 여기/거기/저기, 이분/그분/저분 e 그 para algo já mencionado

Pontuação: 100 por acerto + bônus de rapidez (até 50) + combo (25 por acerto seguido, até 100) + 300 por nível perfeito.
Trilha sonora K-pop e efeitos são sintetizados com Web Audio; a voz em coreano usa a síntese de fala do navegador.
Teclado: 1–4 para responder, Enter para a próxima pergunta.
