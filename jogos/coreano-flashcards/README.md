# 이·그·저 Flashcards

Deck de 16 flashcards (HTML5 + JavaScript + Three.js) para praticar os demonstrativos
coreanos da aula de 17/10/2026 (TOPIK I, Ponto A). Abra `index.html` no navegador (precisa
de internet para o Three.js e as fontes).

- Cada card mostra a Ana, o 준호 e o objeto; o aluno escolhe a forma certa ou toca no objeto
  que a frase indica. Depois o card vira em 3D com resposta, tradução, explicação e voz.
- Tipos de card: 이/그/저 + N, apontar o objeto, 이거/그거/저거 뭐예요?, 이것은 …이에요/예요,
  troca de quem fala (준호), 여기/거기/저기, 이분/그분/저분, 그 para algo já citado e
  "erro comum: está certo?".
- Card errado volta 3 cards depois (com nova situação). O jogo termina quando os 16 forem dominados.
- Pontos: 100 de primeira + bônus de rapidez (até 50) + combo (até 100); acerto em revisão vale 50 + combo.
- Trilha K-pop e efeitos sintetizados com Web Audio; confetes 3D em Three.js.
- Teclado: 1–4 para responder (nos cards de apontar: 1 = Ana, 2 = 준호, 3 = longe), Enter para o próximo card.
