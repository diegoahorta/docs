# Mayu e o Gato de Nekomori (マユと猫の森)

Jogo 2D em um único arquivo (`index.html`, sem dependências) para a **Lição 29 de japonês — あっ、忘れてしまいました！**, seguindo a sequência Odu Creative: INPUT → INTAKE → RETRIEVAL → OUTPUT → SPACED REVIEW.

Abra `index.html` no navegador para jogar.

- 9 missões em sequência (cada uma só abre quando a anterior termina), espelhando as seções da aula: Input, ～ています, ～てしまいました, Chunking, Escrita manual, Missão 忘れ物, どうしたんですか, Retrieval e Checkout; no final, a tabela de revisão espaçada.
- Montagem de frases com blocos (chunks), pistas graduais e pontuação sem punição: ★ reconheceu · ★★ com ajuda · ★★★ sem ajuda · ★★★★ acrescentou informação.
- Explosão de confetes, carimbos, flash, tremor de tela e sons a cada acerto, com frases motivacionais.
- Trilha dark fantasy gerada com Web Audio (drone, pad em ré menor harmônico, coro, caixinha de música, sino), leitura das frases em voz alta (ja-JP) e progresso salvo no navegador.
