# Pongo no Mundo do Hangul · 한글 나라의 퐁고

Jogo de alfabetização em coreano: o Senhor Tromba sumiu no Mundo do Hangul e o Pongo precisa aprender a ler
para seguir as pistas. Trilha progressiva em 7 terras e 17 fases, pensada para o celular.

| Terra | Conteúdo |
| --- | --- |
| 모음 마을 · Vila das Vogais | ㅇ mudo, ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ, ㅑ ㅕ ㅛ ㅠ |
| 자음 숲 · Floresta das Consoantes | ㄱ ㄴ ㄷ ㄹ, ㅁ ㅂ ㅅ, ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ |
| 음절 다리 · Ponte das Sílabas | vogal em pé (à direita) e deitada (embaixo), tabela 가나다 |
| 쌍자음 언덕 · Colina das Duplas | ㄲ ㄸ ㅃ ㅆ ㅉ e o contraste normal / com sopro / apertado |
| 이중모음 호수 · Lago das Compostas | ㅐ ㅔ ㅒ ㅖ, ㅘ ㅙ ㅚ ㅝ ㅞ ㅟ ㅢ |
| 받침 동굴 · Caverna do Batchim | os 7 sons finais, batchim duplo (닭, 값) e ligação (음악 → [으막]) |
| 단어 성 · Castelo das Palavras | montar palavras inteiras e ler as frases finais para achar o Tromba |

Tipos de exercício: cartão da letra (som, dica para lembrar, nome), ler e escolher a pronúncia, ouvir e escolher,
montar sílabas com peças coloridas (azul = consoante, rosa = vogal, amarelo = batchim, com o bloco mostrando
onde cada peça fica), escrever palavras com figura, ler e escolher a figura, som final do batchim, pronúncia
real e pistas do Tromba. Erros voltam no fim da fase. Botão "Alfabeto" com a tabela completa para ouvir.

Abra `index.html` no navegador. Editar: `src/game.html`, depois `python3 tools/build.py`.
