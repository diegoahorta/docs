# Pongo: expressões e reações

`pongo_expressoes_folha.webp` (640 × 582) é a folha original com 16 quadros rotulados e uma
pose de corpo inteiro. Os PNGs são recortes de 96 × 96 do rosto de cada quadro, usados como
retrato do narrador no jogo.

| Arquivo | Quadro | Uso no jogo |
|---------|--------|-------------|
| `feliz.png` | Feliz | Padrão, chefe derrotado, opção |
| `piscando.png` | Piscando | Tiro duplo, escudo |
| `empolgado.png` | Empolgado | Início da fase 1, laser, esferas 人 語, sino verde |
| `curioso.png` | Curioso | Fase 2, cápsula, partícula nova |
| `surpreso.png` | Surpreso | Chefe chegando |
| `sonolento.png` | Sonolento | Pausa |
| `carinhoso.png` | Carinhoso | Vida extra |
| `brincalhao.png` | Brincalhão | Velocidade |
| `atento.png` | Atento | Fase 3, mísseis |
| `bravo.png` | Bravo | Dano, sino azul |
| `assustado.png` | Assustado | Dano, última vida |
| `pensativo.png` | Pensativo | Partícula repetida |
| `triste.png` | Triste | Fim de jogo |
| `com_osso.png` | Com osso | Sino dourado |
| `barriga.png` | De barriga pra cima | Fase concluída |
| `tchau.png` | Tchau! | Tela final |

Os quadros não estão numa grade regular; as coordenadas de recorte foram escolhidas à mão.
