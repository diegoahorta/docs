# Palmeira de fundo (animada)

Palmeira com tronco curvo e copa verde em cores dessaturadas, pensada para uma
camada de fundo atrás do tileset principal.

| Item | Valor |
|------|-------|
| Frames | 4 (`frames/frame_01.png` … `frame_04.png`) |
| Tamanho do frame | 51 × 53 px (RGBA) |
| Animação | Copa balançando ao vento, em loop (tronco parado) |
| Velocidade sugerida | ~150 ms por frame |
| Paleta (6 cores) | Copa `#5a8780` `#75a296` `#96b9a7`; tronco `#6e5c64` `#a98178` `#c7a693` |

- `spritesheet.png`: tira 204 × 53 (4 × 51 px)
