# Explosão / flash branco (incompleta)

Formas brancas sólidas (`#ffffff`) sobre fundo transparente, em quadro de 82 × 72 px.
Pelo formato, parece o começo de uma explosão: um círculo pequeno, depois um maior,
depois o círculo se abrindo em anéis.

| Frame | Área ocupada |
|-------|--------------|
| `frame_01.png` | x 29–54, y 26–50 (círculo pequeno) |
| `frame_02.png` | x 20–63, y 17–59 (círculo grande) |
| `frame_03.png` | x 13–74, y 11–65 (círculo se partindo em anéis) |

Como é só branco, dá para tingir na engine (modulate/tint) com a cor desejada.
Faltam os frames seguintes (provavelmente 5), que não chegaram como arquivo.
