# Sprites

Arte em pixel art para um jogo ambientado em São Paulo.

| Arquivo | Conteúdo |
| --- | --- |
| `sao-paulo-cenario-tileset.webp` | Tileset de cenário: MASP, edifícios (Copan e outros), casas, comércio, muros, janelas, ônibus, carro, moto, ponto de ônibus, banca, feira, postes, calçada em pedra portuguesa, asfalto, placas, lixeira, banco, árvores, orelhão |
| `personagem-pegar-garrafa-pedra.webp` | Personagem agachando e pegando objetos (4 linhas × 6 quadros): garrafa (esquerda/direita) e pedra (esquerda/direita) |
| `personagem-andar-direita.png` | Personagem parado de frente + ciclo de caminhada (4 quadros) |
| `personagem-pular-acenar.png` | Personagem: parado de perfil, pulo (3 quadros), aceno e pose de frente |
| `personagem-andar-direita-2.png` | Variação do ciclo de caminhada (parado de frente + 4 quadros) |
| `personagem-retrato-frente.jpg` | Retrato do personagem de frente, em alta resolução (1728×1152), sorrindo com as mãos nos bolsos |
