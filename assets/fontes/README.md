# Fontes

| Arquivo | Conteúdo |
| --- | --- |
| `small_pixel-7.ttf` | Fonte TrueType "SmallPixel-7", a fonte de origem do bitmap |
| `Fonte_jogo.fnt` | Descritor de bitmap font (formato BMFont/AngelCode): SmallPixel-7, tamanho 20, 64 caracteres (0–9, A–Z, a–z, ponto e espaço), atlas 111×104 |
| `Fonte_jogo.png` | Atlas de glifos referenciado pelo `.fnt`: preenchimento roxo/lilás com contorno escuro |
| `Fonte_jogo_branca.png` | Variante do atlas, mesmo layout: preenchimento branco com contorno roxo-escuro. Para usar, renomeie para `Fonte_jogo.png` ou ajuste `page ... file=` no `.fnt` |
