# public/assets/sprites

Pasta reservada para os assets definitivos (sprites). Na versão atual, a arte e o som são gerados por código (src/art/, src/systems/AudioSystem.js). Para substituir, carregue os arquivos em `src/scenes/PreloadScene.js` com `this.load.*` usando as mesmas chaves de textura (ex.: `pongo`, `npc-lisa`, `bld-station`, `tiles`).
