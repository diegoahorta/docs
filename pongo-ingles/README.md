# Pongo learns English 🐶🇬🇧

Versão em inglês do jogo do Pongo (mesmo motor e sprites de `../pongo-francais`), com foco em:

- **Unit 7** · perguntas no present simple com *do / does*, ordem das palavras, respostas curtas
- **Unit 8** · *I am doing* (present continuous) × *I do* (present simple) e verbos que não vão para o *-ing*
- **Unit 9** · *have / have got*, negativa (*don't have / haven't got*) e perguntas (*Do you have…? / Have you got…?*)

## Arquivos
- `pongo-ingles.html` — **arquivo único** com todas as imagens embutidas; basta abrir no navegador.
- `index.html` — mesma versão usando as imagens de `../pongo-francais/assets/`.
- `conteudo-ingles.js` — perguntas e mini-aulas (fonte do conteúdo das fases).

## Fases
1. *Have you got a bone?* — have / have got (Unit 9)
2. *Do you like bones?* — do / does (Unit 7)
3. *Is Pongo running?* — present continuous × present simple (Unit 8)
4. *Make the sentence!* — montar frases com palavra intrusa
5. *Where is Senhor Tromba?* — diálogo final misturando tudo

Frases de exemplo são originais (universo do Pongo); a gramática segue as unidades do material de referência.
